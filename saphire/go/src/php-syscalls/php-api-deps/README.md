Usage
=============
Install Go: https://golang.org/doc/install
```bash
git clone https://git-seclab.bu.edu/php-syscalls/php-api-deps $GOPATH/src/php-api/deps
cd $GOPATH/src/php-api/deps
./profile_application.sh PATH_TO_APP_ROOT PATH_TO_OUTPUT_PROFILE
# eg ./profile_application.sh ~/apps/phpBB2/ phpBB2.sqlite
```
